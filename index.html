Guía de Despliegue en Netlify (README)

1. Despliegue en Netlify

Puedes publicar este proyecto en Netlify de dos maneras:

  • Opción A (Arrastrar y soltar): Arrastra la carpeta raíz que contiene este index.html directamente a la consola de Netlify Drop.
  • Opción B (Git/GitHub): Conecta el repositorio en Netlify. Se detectará automáticamente la configuración en netlify.toml.

2. Configurar la Variable de Entorno

Para proteger la API Key de Gemini y evitar que quede expuesta en el código cliente:

  1. Obtén tu API Key gratuita en Google AI Studio.
  2. En Netlify, ve a Site Configuration > Environment Variables.
  3. Crea la variable GEMINI_API_KEY con el valor de tu clave.

3. Resiliencia de Modelos Automática

El cliente y la función proxy prueban en secuencia la lista de modelos gratuitos:

gemini-3-flash-preview → gemini-2.5-flash → gemini-2.5-flash-lite → gemini-1.5-flash

Si la lista fija falla, el sistema descubre automáticamente los modelos activos disponibles mediante el endpoint de listado de modelos de Google.

4. Personalización de Créditos e Imagen

Para actualizar los datos del docente responsable:

  • Coloca tu foto en la carpeta raíz nombrada como yo.jpg (o ajusta la ruta en el HTML).
  • Edita el modal de créditos en el código fuente para actualizar la institución, correo o nivel de Bachillerato.
